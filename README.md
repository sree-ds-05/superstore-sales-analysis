# superstore-sales-analysis

## Objective
Analyze retail sales data to identify trends, profitable regions, and top-performing products.

## Dataset
Sample Superstore Dataset (9,995 records)

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts

## Key Findings
- Technology was the highest-selling category.
- West Region generated the highest profit.
- Sales increased from 2014 to 2017.
- Canon imageCLASS 2200 Advanced Copier was the top-selling product.
